# Interactive dashboard demonstration

Open [`performance_review_dashboard.html`](performance_review_dashboard.html) in a browser, or use the hosted [GitHub Pages demo](https://nickjd.github.io/BranchManager/demo/).

## Faithfulness to BranchManager

This dashboard was generated by the current `branchmanager.reporting.write_performance_review_dashboard()` function from the synthetic TSV and JSON files in this directory. It is not a separately designed mock-up or a simplified replacement. Its layout, navigation, charts, filters, paginated tables, isolate detail drawer, pangenome group membership drawer, novelty comparison panel, genome collection section, phylogeny gallery and source-file links are provided by the same dashboard generator used for Performance Review outputs.

The demo records are synthetic and were created only to populate the current report schema. Names, partners, taxonomic lineages, identity values, QC categories, novelty comparisons, genome records, pangenome targets and recommendations are illustrative. They are not experimental results, GTDB assertions or recommendations for real isolates.

## Contents

- `performance_review_dashboard.html` — generated interactive report.
- `assessment/` — synthetic selection, sequence assessment, novelty, pangenome, genome and neighbourhood inputs used to generate the report.
- `taxonomy/` — synthetic per-database taxonomy tables read by the dashboard generator.
- `run_manifest.json` — demonstration provenance.

The dashboard is self-contained apart from its linked TSV, JSON and PNG files, which are included alongside it. It does not call a backend or access a live database.

## Publishing the hosted demo

The repository includes `.github/workflows/deploy-demo.yml`. It regenerates this dashboard from the committed synthetic fixtures and publishes the `docs/` directory to GitHub Pages when relevant reporting code, demo fixtures or documentation change on `main`, or when the workflow is run manually. See [the GitHub Actions setup guide](../GITHUB_ACTIONS_SETUP.md) for configuration details. In the repository settings, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**. After the first successful workflow run, the hosted demo is available at `https://nickjd.github.io/BranchManager/demo/`.
