# BranchManager v1.2.0

## Sanger-Studio improvements

This release introduces several improvements to Sanger-Studio, focusing on resequencing support, read selection, alignment review and chromatogram interpretation.

### New features and improvements

- **Resequencing support:** Multiple sequencing attempts for the same isolate and primer can now be imported and reviewed together.
- **Read selection:** Alternative reads are assessed individually, allowing the user to select the most appropriate read for each primer before assembly.
- **Improved manifest generation:** Duplicate sequencing attempts are retained as separate records with distinct identifiers rather than being overwritten.
- **Safer file resolution:** Directory-qualified sequencing file references are resolved within their submission context, reducing the risk of incorrectly matching files from different sequencing batches.
- **Multi-read alignment review:** Selected reads can be inspected against candidate sequences, with disagreements highlighted for review.
- **Chromatogram orientation correction:** Reverse reads are now interpreted in assembly orientation when displaying fluorescence-channel evidence.
- **Improved trace inspection:** Interactive chromatogram inspection provides clearer nucleotide/channel evidence at selected alignment positions, including peak-aligned comparisons.
- **Assembly review workflow:** Read selection and candidate assembly selection are more closely integrated, with assembly candidates updating in response to selected reads.

### Improvements to reliability

- Improved handling of multiple reads originating from the same primer.
- Better separation of raw sequencing evidence, read selection and assembly decisions.
- Additional regression tests for resequencing, file resolution, read mapping and chromatogram channel orientation.

### Notes

This release improves the interpretation and review of sequencing evidence but does not replace manual inspection. Ambiguous chromatogram signals, conflicting reads and uncertain assemblies should still be reviewed before downstream analysis.
